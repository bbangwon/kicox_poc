# 사내 규정 Q&A 에이전트 MCP 도구 설계 (MCP Tool Design)

> ⚠️ **이전 단계 문서 (MCP 오케스트레이션 PoC)**. `mcp_servers/`와 `planner → agent ⇄ tools` 구조는 제거됐습니다. 도구는 전처리 저장소가 문서별로 추출 · 승인한 `formula` / `table_lookup` spec으로 바뀌었고(실행기 `backend/tools_exec.py`), 역질문도 `need_info` 대신 tool 노드가 비워 둔 입력값을 ask 노드가 되묻습니다([RAG_DESIGN_NOTES.md](RAG_DESIGN_NOTES.md) §5.4-6~7). 지금 참조하는 부분은 **§5 규정 공백 목록**과 **부록 A 기준 수치**(파싱 정답 확인용)뿐입니다.

본 문서는 `docs/`의 사내 규정 PDF 2종을 매뉴얼로 사용하는 한국어 Q&A 에이전트에서, 오케스트레이터(LangGraph `planner → agent ⇄ tools`)가 MCP로 호출할 도구를 정리한 문서입니다.

- **도구 선정 기준**: 직원 문의가 잦을 것으로 보이는 질문을 우선합니다. 저빈도 질문은 별도 계산 도구 없이 규정 조회 도구로 대응합니다.
- **정보 수집 방식**: 계산에 필요한 정보가 부족하면 도구가 `need_info`와 역질문을 반환하고, LLM이 **멀티턴 대화**로 사용자에게 받아 와서 다시 호출합니다. 도구는 추측하지 않고, LLM은 계산하지 않습니다.

| 원천 문서 | 분량 | 주요 내용 |
| :--- | :--- | :--- |
| `1. 개인교육훈련비 지원 기준 및 참고자료.pdf` (인사팀) | 2p | 지원대상/제외대상, 과세여부, MIS 교육신청 입력 항목, 이수학점 지급기준 |
| `한국산업단지공단 여비업무 처리기준(250909).pdf` (상생복지팀) | 20p | 출장유형 분류, 유형별 여비, 국외 체재비표, 부임여비·이전비·가족여비, 자동차 운임, 항공마일리지, 국가 등급표 |

> 위 두 PDF는 설계 검토용 테스트 자료여서 삭제했습니다. 필요하면 git 이력(`0fd120c`)에서 복원할 수 있습니다.

## 1. 문의 빈도 분석

규정의 적용 대상 범위와 발생 주기, 그리고 계산 복잡도(직원이 혼자 계산하기 어려운 정도)를 기준으로 판단했습니다.

| 순위 | 문의 유형 | 대표 질문 | 빈도 | 판단 근거 | 대응 도구 |
| :---: | :--- | :--- | :---: | :--- | :--- |
| 1 | **국내 출장비 계산** (당일·숙박 모두) | "내일 ○○ 다녀오는데 출장비 얼마 나와요?", "1박 2일이면 얼마예요?" | ★★★ | 전 직원 대상이고 매일 발생합니다. 거리·행정구역·시간·차량·직급·식사 제공에 따라 금액이 달라져 혼자 계산하기 어렵습니다 | **T1** |
| 2 | **출장 종류 선택** (MIS 신청) | "같은 시인데 왕복 100km면 뭐로 신청해요?" | ★★★ | MIS 신청 시 출장종류를 직접 골라야 하는데, 시내/시외/특별당일귀임 기준이 헷갈리기 쉽습니다 | **T1** (분류 결과 포함) |
| 3 | **숙박비 인정액** | "숙박비 9만원 썼는데 다 받아요?", "서울 하루, 경기 하루 잤어요" | ★★★ | 숙박 출장마다 발생합니다. 지역별 상한과 총액 한도 방식, 30% 가산 규정이 복잡합니다 | **T2** |
| 4 | **교육 지원 가능 여부·과세** | "이 자격증 학원비 지원돼요?", "토익은 과세예요?" | ★★★ | 교육신청 전에 반드시 확인하는 사항입니다. 제외 대상의 경계(투자, 취미, 취업준비)를 판단해야 합니다 | **E1** |
| 5 | **이수학점** | "7시간 교육 들으면 몇 학점이에요?" | ★★☆ | 직무직급 교육을 신청할 때마다 이수학점을 입력해야 합니다 | **E2** (구현됨) |
| 6 | **증빙서류·신청 경로** | "출장 정산할 때 뭐 첨부해요?", "교육신청 메뉴 어디예요?" | ★★☆ | 자주 묻지만 계산은 필요 없습니다 | **R1·R2** (조회) |
| 7 | **자가용 운임** | "자차로 갔는데 기름값 얼마 받아요?" | ★★☆ | 지방 출장에서 자주 발생합니다. 거리 × 유가 ÷ 연비 계산과 인정 사유 판단이 필요합니다 | **T3** |

## 2. 멀티턴 정보 수집 설계

### 2.1 슬롯 분류

각 도구의 입력을 다음 세 가지로 나눕니다. 이렇게 하면 질문 횟수를 줄이면서도 금액을 추측하지 않을 수 있습니다.

| 분류 | 의미 | 없을 때 도구 동작 |
| :--- | :--- | :--- |
| **필수** | 없으면 금액이 결정되지 않음 (예: 직급, 거리) | `need_info`로 역질문 |
| **조건부 필수** | 다른 슬롯 값에 따라 필요해짐 (예: 시내출장일 때만 출장 시간) | 해당 조건일 때만 역질문 |
| **선택(기본값)** | 대부분 기본값이 맞는 값 (예: 식사 제공 0끼) | 기본값으로 계산하고 `assumptions`에 명시 → 답변에서 "식사를 제공받지 않았다면"처럼 전제를 안내 |

### 2.2 `need_info` 응답 스키마

기존 `calculate_training_credits`의 형식을 확장합니다.

```json
{
  "status": "need_info",
  "known": {"trip_type": "국내출장", "nights": 1, "region": "광역시"},
  "missing": ["grade", "used_company_vehicle"],
  "questions": [
    {"slot": "grade", "text": "직급이 어떻게 되시나요?", "options": ["임원", "1급", "2급 이하"]},
    {"slot": "used_company_vehicle", "text": "업무용 차량(또는 임차 차량)을 이용하시나요?", "options": ["예", "아니오"]}
  ],
  "partial_result": {"lodging_cap": 80000, "note": "광주(광역시) 숙박 상한은 1박 80,000원입니다"}
}
```

| 필드 | 용도 |
| :--- | :--- |
| `known` | 지금까지 확정된 값. LLM이 다음 턴에 다시 호출할 때 그대로 넘깁니다 |
| `questions[].options` | 선택지. 사용자가 "2번"처럼 짧게 답할 수 있습니다 |
| `partial_result` | 지금 정보만으로 확정된 부분 결과. 역질문과 함께 보여주면 대화가 덜 답답합니다 |

### 2.3 대화 운영 규칙 (`AGENT_PROMPT` 반영)

1. **한 번에 묶어서 묻습니다.** `questions`를 번호 목록으로 한 번에 제시하고, 최대 3~4개까지만 묻습니다. 나머지는 다음 턴에 묻습니다 (도구가 중요도 순으로 정렬해 반환).
2. **사용자가 이미 말한 값은 다시 묻지 않습니다.** 매 호출에 대화 전체에서 확인된 슬롯을 모두 넘깁니다. 같은 `thread_id`의 히스토리가 슬롯 저장소 역할을 합니다.
3. **사용자가 모른다고 하면** 사용자가 쉽게 답할 수 있는 다른 슬롯으로 바꿔 묻습니다. 예를 들어 왕복 km를 모르면 출장지 도시명을 받아서 "네이버 지도 최단거리"로 확인하는 방법을 안내하거나, 구간 경계에 해당하는지("왕복 120km가 넘나요?")만 묻습니다.
4. **사전 예상과 사후 정산을 구분합니다.** 출장 전에는 실제 숙박비·운임을 모르는 것이 정상입니다. 이 경우 실비 항목은 "상한/실비 별도"로 두고 **예상 최대액**을 안내합니다 (`mode="예상"`).
5. **`assumptions`는 반드시 답변에 노출합니다.** 기본값으로 계산한 전제가 틀리면 사용자가 정정할 수 있어야 합니다.
6. 직급처럼 반복해서 묻게 되는 값은 이후 사용자 프로필(SSO/MIS)에서 미리 채우도록 확장할 수 있습니다 (§6).

## 3. 도구 명세 (빈도 순)

### T1. `calculate_domestic_trip_expense`: 국내 출장비 (문의 1·2순위)

**목적**: 당일 출장(시내/시외/특별당일귀임)과 숙박 국내출장을 하나의 진입점으로 처리합니다. 도구가 **출장유형을 먼저 판정하고, 그 유형에 필요한 슬롯만 역질문**합니다. 결과에는 MIS 출장종류, 금액 내역, 증빙 목록이 포함됩니다.

```python
def calculate_domestic_trip_expense(
    mode: str = "예상",                       # 예상(출장 전) | 정산(출장 후, 실제 지출 기준)
    nights: int | None = None,
    round_trip_km: float | None = None,
    same_admin_area: bool | None = None,
    destination_city: str | None = None,      # 숙박 지역 상한 판정용 (서울/광역시/기타 자동 분류)
    duration_hours: float | None = None,
    used_company_vehicle: bool | None = None,
    grade: str | None = None,                 # 임원 | 1급 | 2급이하
    transport: str | None = None,             # 대중교통 | 자가용
    fare_legs: list[dict] | None = None,      # [{"standard": 43500, "actual": 30000}] 편도 단위
    lodging: list[dict] | None = None,        # T2와 동일 형식
    days: int | None = None,
    meals_provided: int = 0,
    event_provision: str | None = None,       # 공단주최_숙식교통 | 공단주최_숙식 | 외부_숙식교통 | 외부_숙식
    accompanying_superior_grade: str | None = None,
    is_assigned_driver: bool = False,
) -> dict
```

**슬롯 정의 및 역질문**

| 슬롯 | 분류 | 필요 조건 | 역질문 문구 (선택지) | 기본값 |
| :--- | :--- | :--- | :--- | :--- |
| `nights` | 필수 | 항상 | "당일 출장인가요, 숙박하는 출장인가요? 숙박이면 몇 박인가요?" | - |
| `round_trip_km` | 조건부 | 당일 | "근무지 → 출장지 → 근무지 왕복 거리가 얼마인가요? (네이버 지도 최단거리 기준)" — 모르면 "왕복 120km를 넘나요? 240km를 넘나요?" (12~120 / 120~240 / 240 초과) | - |
| `same_admin_area` | 조건부 | 당일, 왕복 12~120km | "출장지가 근무지와 같은 시·군인가요?" (예/아니오) | - |
| `duration_hours` | 조건부 | 시내출장 | "출장 시간이 4시간 이상인가요? (이동시간·점심시간 포함)" (4시간 미만/이상) | - |
| `used_company_vehicle` | 필수 | 항상 | "업무용 차량이나 임차 차량을 이용하시나요?" (예/아니오) | - |
| `grade` | 조건부 | 특별당일귀임 운임 등급, 숙박 출장 | "직급이 어떻게 되시나요?" (임원/1급/2급 이하) | - |
| `destination_city` | 조건부 | 숙박 출장 | "어느 지역에서 숙박하시나요?" | - |
| `transport` | 조건부 | 운임 발생 유형 | "이동수단은 무엇인가요?" (KTX·버스 등 대중교통/자가용) → 자가용이면 T3 연계 | - |
| `fare_legs` | 조건부 | 정산 모드 | "실제 결제한 교통비를 편도별로 알려주세요." | 예상 모드: "운임 실비 별도" |
| `lodging` | 조건부 | 정산 모드 + 숙박 | "1박당 실제 숙박비와 숙박 형태(일반/공단숙소/친지집)를 알려주세요." | 예상 모드: 지역 상한 적용 |
| `days` | 선택 | 숙박 출장 | - | `nights + 1` |
| `meals_provided` | 선택 | 숙박 출장 | 사용자가 행사·교육·워크숍을 언급하면 질문 | 0끼 |
| `event_provision` | 선택 | 행사 참석 | 사용자가 행사·교육·워크숍을 언급하면 "숙식이나 교통을 주최 측에서 제공하나요?" | 제공 없음 |
| `accompanying_superior_grade` | 선택 | - | 사용자가 수행 출장을 언급할 때만 | 없음 |

**판정·계산 로직**

1. **유형 판정** (`nights`, `round_trip_km`, `same_admin_area`)

   | 조건 | 유형 | MIS 출장종류 |
   | :--- | :--- | :--- |
   | 1박 이상 또는 당일 왕복 240km 초과 | 국내출장 | 국내출장 |
   | 당일 왕복 120 초과~240km | 특별당일귀임 | 특별당일귀임 |
   | 당일 왕복 12~120km, 같은 시·군 | 시내출장 | 시내출장(4시간 미만/이상) |
   | 당일 왕복 12~120km, 다른 시·군 | 시외당일귀임 | 시외당일귀임 |
   | 왕복 12km 미만 | 지급 구간 아님 | - (`conditions`: 원문 미규정, 확인 필요) |

2. **당일 출장**: 시내 10,000원(4시간 미만)/20,000원(4시간 이상), 시외 20,000원, 특별 30,000원(일비+식비) + 운임 실비. 업무용 차량을 쓰면 1만원 감액하고, 운전기사의 본연 업무면 0원입니다.
3. **숙박 국내출장**
   - 일비 = 직급 일비 × `days` × (차량 이용 시 0.5) − 운임 편도 초과분
   - 식비 = 직급 식비 × `days` − 8,000 × `meals_provided`
   - 숙박 = T2 로직
   - 운임 = 실비
   - `event_provision`에 따라 지급 항목을 제외합니다 (부록 A).
4. **결과**: `trip_type`, `mis_trip_type`, `breakdown`, `total`, `assumptions`, `conditions`(증빙 요건), `required_documents`

**검증 예시**

| 입력 | 결과 |
| :--- | :--- |
| 당일, 왕복 30km, 같은 시, 5시간, 업무용 차량 | 시내출장(4시간 이상), 20,000 − 10,000 = **10,000원** |
| 당일, 왕복 180km, 대중교통, KTX 왕복 48,000원 | 특별당일귀임, 30,000 + 48,000 = **78,000원** |
| 정산, 2급 이하, 대구 2박 3일, 운임 기준 편도 43,500원(실제 30,000/55,000원), 숙박 85,000+70,000원 | 운임 85,000 + 숙박 135,000 + 일비 63,500(11,500 차감) + 식비 75,000 = **358,500원** |
| 예상, 2급 이하, 광주 1박 2일, KTX, 차량 미이용 | 일비 50,000 + 식비 50,000 + 숙박 최대 80,000 = **최대 180,000원 + 운임 실비** |

### T2. `calculate_lodging_reimbursement`: 숙박비 인정액 (문의 3순위)

**목적**: "숙박비 다 받을 수 있나요?" 같은 단독 질문에 답합니다. T1도 내부에서 이 로직을 재사용합니다.

```python
def calculate_lodging_reimbursement(
    nights: list[dict] | None = None,        # [{"city": "서울", "amount": 90000, "type": "일반|공단숙소|친지집|자택"}]
    surcharge_reason: int | None = None,      # [양식1] 체크리스트 해당 번호 (1~5)
) -> dict
```

| 슬롯 | 분류 | 역질문 | 기본값 |
| :--- | :--- | :--- | :--- |
| 박별 `city` | 필수 | "어느 지역에서 몇 박 하셨나요? 날마다 지역이 다르면 각각 알려주세요." | - |
| 박별 `amount` | 필수 | "1박당 실제 결제한 숙박비는 얼마인가요?" (모르면 상한만 안내) | - |
| 박별 `type` | 선택 | 금액이 0이거나 매우 낮을 때만 질문 | 일반 |
| `surcharge_reason` | 조건부 | 상한 초과 시: "다음 중 해당하는 사유가 있나요? ① 주최기관 숙소 지정 ② 도서·벽지 ③ 결항·재난으로 복귀 불가 ④ 성수기·긴급으로 상한 내 숙소 매진 ⑤ 심야 도착·새벽 회의" (해당 없음 포함) | 없음 |

**로직**
1. 지역별로 묶어 `min(실지출 합계, 지역 상한 × 박수)`를 적용합니다. 상한은 서울 100,000원, 광역시 80,000원, 기타 70,000원입니다.
2. 공단숙소·친지집은 1박 20,000원 정액, 자택은 0원입니다.
3. 가산 사유가 있으면 상한의 130%까지 인정하고, 처리 절차를 반환합니다 (복명 시 숙박비 0원 → 별도 기안, 체크리스트+증빙 첨부).

**검증 예시**: 대구 85,000+70,000원 → **135,000원** / 서울 90,000 + 경기 80,000원 → **160,000원** (경기 초과분 10,000원 불인정)

### E1. `check_training_eligibility`: 교육 지원 가능 여부·과세 (문의 4순위)

**목적**: 교육 내용을 지원범위 카테고리로 분류하는 일은 LLM이 하고, 도구는 분류 결과에 규칙을 적용합니다. 분류가 애매하면 LLM이 추측하지 않고 **사용자에게 업무 연관성을 되묻습니다**.

```python
def check_training_eligibility(
    course_name: str | None = None,
    support_category: str | None = None,   # 현직무 | IDP희망직무 | 직무공통 | 어학 | 기초역량 | 전문성강화 | 전직지원
    idp_rank: int | None = None,
    is_wage_peak: bool | None = None,
    exclusion_flags: list[str] | None = None,  # 사적물품포함 | 부대비만지출 | 개인취미 | 투자관련 | 범위외자격증 | 취업이직준비
    exclusion_checked: bool = False,           # LLM이 제외대상 해당 여부를 검토했는지
) -> dict
```

| 슬롯 | 분류 | 역질문 (선택지) | 비고 |
| :--- | :--- | :--- | :--- |
| `course_name` | 필수 | "어떤 교육(또는 자격증)인가요?" | - |
| `support_category` | 필수 | 업무 관련 교육으로 보이면: "이 교육이 ① 현재 담당 업무와 관련 있나요, ② IDP 희망직무와 관련 있나요, ③ 경영·경제·행정·법 등 직무공통 교육인가요?" | 어학·OA·학위는 LLM이 바로 분류 가능 |
| `idp_rank` | 조건부 | "IDP에 등록한 희망직무 몇 순위인가요? (MIS → 교육관리 → IDP 관리에서 확인 가능)" | 1~3순위만 인정 |
| `is_wage_peak` | 조건부 | 전직지원 교육일 때: "임금피크 적용 대상이신가요?" | - |
| `exclusion_flags` | 조건부 | 애매할 때만: "수강료에 태블릿 등 기기가 포함되어 있나요?", "교재비만 지출하시나요?" | 명백하면 LLM이 판정 |

**로직**: 제외 사유가 있으면 불가 → 카테고리별 과세 판정(직무 3종은 비과세, 공통·전직지원은 과세) → MIS 입력 가이드를 반환합니다.

| support_category | 과세 | 학점구분 | 직무구분 | 직무적합·직무근거 | 학점신청 |
| :--- | :---: | :--- | :--- | :---: | :---: |
| 현직무 | 비과세 | 직무직급 | 현직무 | 필요 | 가능 |
| IDP희망직무 | 비과세 | 직무직급 | 희망직무 | 필요 | 가능 |
| 직무공통 | 비과세 | 직무직급 | 기타 | - | 가능 |
| 전문성강화(학위) | 과세 | 직무직급 | 학위취득 | - | 가능 (학기당 2학점) |
| 어학 / 기초역량 | 과세 | 공통 | 기타 | - | **불가** |
| 전직지원(임금피크) | 과세 | - | - | - | - |

### T3. `calculate_car_fare`: 자가용 운임 (문의 7순위)

```python
def calculate_car_fare(
    one_way_km: float | None = None,
    fuel_type: str | None = None,        # 휘발유 | 경유 | LPG | 하이브리드 | 플러그인하이브리드 | 전기 | 수소

) -> dict
```

| 슬롯 | 분류 | 역질문 (선택지) | 기본값 |
| :--- | :--- | :--- | :--- |
| `justification` | 필수 (먼저 질문) | "자가용 운임은 부득이한 사유가 있을 때만 인정됩니다. 해당하는 사유가 있나요? ① 대중교통 없음(산간·도서) ② 경로가 복잡함 ③ 심야·긴급 ④ 무거운 수하물 ⑤ 자가용이 더 저렴 ⑥ 대중교통으로는 일정 소화 불가 ⑦ 환승비 과다 ⑧ 없음" | - |
| `one_way_km` | 필수 | "근무지에서 출장지까지 편도 거리가 몇 km인가요? (네이버 지도 최단거리)" | - |

```python
def calculate_overseas_trip_expense(
    grade: str | None = None,          # 이사장 | 부이사장·이사 | 1급 | 2급 | 3급이하  (3급 팀장·지사장은 2급)
    segments: list[dict] | None = None, # [{"destination": "도쿄", "days": 5, "nights": 3}]
    used_company_vehicle: bool = False,
    is_team_or_branch_head: bool | None = None,
) -> dict
```

| 슬롯 | 분류 | 역질문 (선택지) | 기본값 |
| :--- | :--- | :--- | :--- |
| `grade` | 필수 | "직급이 어떻게 되시나요?" (이사장/부이사장·이사/1급/2급/3급 이하) | - |
| `is_team_or_branch_head` | 조건부 | 3급일 때: "팀장이나 지사장 직책이신가요?" (2급 기준 적용) | - |
| `segments[].destination` | 필수 | "방문 도시를 알려주세요. 여러 곳이면 도시별로 알려주세요." | - |
| `segments[].days/nights` | 필수 | "도시별 일정이 몇 박 며칠인가요?" | 1개 도시면 `days = nights + 1` |
| `used_company_vehicle` | 선택 | 단체출장·전세버스를 언급하면 질문 | 아니오 |

**로직**: 일비 × days (차량 이용 시 ×0.5) + 숙박비 × nights + 식비 × days (USD). 운임·부대비는 실비라 항목만 안내합니다. 표에 없는 국가는 `not_found`로 반환하고 담당 부서 확인을 안내합니다.

**검증 예시**: 3급 이하(팀장 아님), 도쿄 3박 5일 → 150 + 528 + 405 = **USD 1,083**

### T5. `calculate_relocation_allowance`: 전보 시 부임여비·이전비·가족여비 (문의 9순위)

인사발령 시기에 문의가 몰립니다. 대상 여부, 금액, **신청 기한(날짜)**을 함께 반환합니다. 날짜 계산은 LLM이 틀리기 쉬우므로 도구가 처리합니다.

```python
def calculate_relocation_allowance(
    item: str | None = None,                  # 부임여비 | 이전비 | 가족여비 | 전체
    order_date: str | None = None,            # 인사발령일 YYYY-MM-DD
    from_city: str | None = None,
    to_city: str | None = None,
    same_region_hq: bool | None = None,       # 동일 지역본부 내 이동
    one_way_km: float | None = None,
    one_way_fare: int | None = None,
    grade: str | None = None,
    moving_type: str | None = None,           # 1인(사택 기점·종점) | 가족전체
    moving_cost: int | None = None,
    move_date: str | None = None,
    family: list[dict] | None = None,         # [{"relation": "배우자|자녀|부모|형제자매", "age": 8, "married": false}]
    family_arrival_date: str | None = None,
) -> dict
```

| 슬롯 | 분류 | 역질문 | 비고 |
| :--- | :--- | :--- | :--- |
| `item` | 필수 | "부임여비(본인 교통비 등), 이사비(이전비), 가족 교통비(가족여비) 중 무엇이 궁금하신가요? 전부 안내해 드릴 수도 있습니다." | - |
| `from_city`, `to_city` | 필수 | "전임지와 신임지가 어디인가요?" | 수도권·동일 시군 판정 |
| `same_region_hq`, `one_way_km` | 조건부 | 부임여비: "같은 지역본부 내 이동인가요? 그렇다면 편도 거리가 120km를 넘나요?" | - |
| `order_date` | 조건부 | 기한 안내 시: "인사발령일이 언제인가요?" | - |
| `moving_type`, `moving_cost` | 조건부 | 이전비: "혼자 이사하시나요, 가족 전체가 이사하시나요? 이사 견적 금액은요?" | 금액이 없으면 상한만 안내 |
| `family` | 조건부 | 가족여비: "함께 이사하는 가족의 관계와 나이를 알려주세요." | 부양·동거 여부도 확인 |

**로직 요약**
- **부임여비**: 수도권·동일 시군·동일 지역본부 내 이동이면 미지급(편도 120km 초과 시 지급). 교통비(편도) + 일비·식비 2일 + 숙박 1일. 기한은 발령 후 1주일 이내입니다.
- **이전비**: 동일 시·군·섬 간 이동이면 미지급. 실비 지급, 상한은 1인 150만원, 가족 300만원입니다. 발령 후 1년 이내 이사, 이사 후 6개월 이내 신청합니다.
- **가족여비**: 대상은 부양하는 동거가족(배우자, 미혼 직계비속, 직계존속, 만 20세 미만 형제자매). 1인당 본인 편도 교통비이며, 6~11세는 1/2입니다. 이전 후 1년 이내 불러와야 하고, 불러온 날부터 6개월 이내 신청합니다.

**검증 예시**: 가족 이사 견적 340만원 → **300만원**(상한). 본인 편도 50,000원 기준 배우자 + 자녀(8세) → **75,000원**. 발령일 2026-10-14 → 부임여비 신청기한 **2026-10-21**

### R1·R2. 조회 도구 (문의 6·10순위)

계산은 필요 없지만 문의가 잦은 증빙·신청 경로, 그리고 저빈도 규정(항공마일리지 등)은 원문 조회로 대응합니다.

| 도구 | 섹션 |
| :--- | :--- |
| `get_training_policy` (구현됨) | 지원범위, 제외대상, 신청방법, 학점구분, 직무구분, 이수학점 |
| `get_travel_policy` (신규) | 출장유형, 증빙서류, 신청경로(MIS), 자가용인정사유, 숙박비가산체크리스트, 국외출장(부대비·정산·환율), 항공마일리지, 부임·이전·가족여비 |

`get_travel_policy`는 이미지로만 있는 수치를 **사람이 텍스트로 정리해서** 넣어야 합니다 (부록 A 재사용).
